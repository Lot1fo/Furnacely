# Furnacely

Sequential 3-item smelt queue, fuel reserve, and freeze-on-empty for the vanilla furnace. No speed boosts, no new blocks — pure quality-of-life.

Furnacely makes the ordinary furnace practical: load up to three items in sequence, keep fuel reserves behind the active slot, and let the furnace freeze when empty. When the queue runs out, it stops and preserves remaining fuel; it resumes automatically on a new insert. Same recipes, same speed, same results — only the convenience is new.

### FEATURES

- 3-slot sequential queue with dynamic 1 / 2 / 3 numbering.
- Fuel reserve: 1 active + 2 reserve slots, auto-refill.
- Extra output capacity; vanilla stop-if-full preserved.
- Freeze-on-empty: stops and preserves fuel; resumes automatically.

No new block — the vanilla furnace is modified directly.
